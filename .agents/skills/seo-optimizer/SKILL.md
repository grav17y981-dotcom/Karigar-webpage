When optimizing SEO:

1. Check page title and meta description.
2. Check heading hierarchy.
3. Use semantic HTML where possible.
4. Ensure each page has a clear topic and keyword focus.
5. Improve copy clarity without keyword stuffing.
6. Add Open Graph and social preview metadata when appropriate.
7. Check image alt text.
8. Check internal linking opportunities.
9. Keep URLs clean and readable.
10. Make recommendations that support both users and search engines.

For implementation:

- use one clear H1 per main page
- use descriptive section headings
- write concise page metadata
- avoid duplicate titles/descriptions
- ensure important content is not hidden only inside canvas/WebGL
- provide fallback text for 3D or highly visual sections
