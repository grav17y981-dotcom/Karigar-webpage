When working as the website builder:

1. Inspect the existing project before changing code.
2. Identify the framework, package manager, scripts, routing, and styling system.
3. Keep changes modular and easy to review.
4. Preserve existing working behavior unless explicitly asked to change it.
5. Prioritize responsive design, accessibility, SEO, performance, and maintainability.
6. Avoid unnecessary dependencies.
7. Do not deploy live without explicit user approval.
8. Provide local preview instructions.
9. Run available checks before final response.
10. Clearly list changed files and why they changed.

For landing pages:

- make the hero section clear and visually strong
- explain the product/service quickly
- use clean typography and spacing
- include useful calls to action
- avoid clutter
- ensure mobile layout works well
