When working on 3D website features:

1. Inspect the current 3D scene structure before editing.
2. Keep the scene lightweight and performant.
3. Use lazy loading for heavy 3D assets.
4. Avoid huge textures and unnecessary geometry.
5. Make animations smooth but not distracting.
6. Respect reduced-motion preferences.
7. Ensure the site still works if 3D fails or loads slowly.
8. Test desktop and mobile behavior.
9. Do not add large dependencies without explaining why.
10. Run available checks before final response.

For Karigar-style direction:

- the 3D concept should feel like a clean modern garage or workbench
- the wordmark intro may zoom out into a workbench/tools environment
- the site should feel premium and practical, not like a chaotic game menu
- animations should guide attention, not distract from the message
- preserve readability and loading speed
