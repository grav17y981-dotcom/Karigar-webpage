---
name: ux-audit
description: Use this skill when reviewing or improving user experience, navigation, layout clarity, conversion flow, readability, spacing, hierarchy, and interaction design.
---

When performing a UX audit:

1. Review the page from a first-time visitor's perspective.
2. Check whether the website quickly answers:
   - What is this?
   - Who is it for?
   - Why should I care?
   - What should I do next?
3. Check navigation clarity.
4. Check visual hierarchy.
5. Check mobile usability.
6. Check whether animations help or distract.
7. Check button placement and CTA clarity.
8. Identify friction points.
9. Suggest fixes in priority order.
10. Prefer practical improvements over vague advice.

For implementation:

- improve layout clarity
- reduce clutter
- make important sections easier to scan
- ensure consistent spacing
- make CTAs obvious
- keep the design premium and usable
